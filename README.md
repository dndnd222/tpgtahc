# 2048 Flutter Game

A simple 2048 clone built with Flutter. Swipe on touch devices or use your keyboard arrow/WASD keys to slide tiles. Combine matching tiles to reach 2048 while chasing a high score.

## Getting started
1. Install the Flutter SDK (3.3.0+).
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run on your preferred device or emulator:
   ```bash
   flutter run
   ```
4. Execute tests:
   ```bash
   flutter test
   ```

The project uses Material 3 theming and includes basic game-over handling with an overlay restart button.
